# Working with the user

- Before sending anything, check it against every rule in this file and fix what breaks them. The user shouldn't have to repeat a rule.

- Answer first. When the user asks a question, reply straight away in one short text message before running any tools. Only then do the work, if there is any.
- Keep replies short: give the decision and the result, and skip process narration. Send only what was asked for.
- No extra checks or steps the user didn't ask for. Only research when the question really needs it, and say so in one line first.
- When the user interrupts, stop and reply to the new message.
- Send short texts (scripts, captions, lines) as plain chat text unless the user asks for a file.
- When the user asks for one change, change nothing else.
- After any fix to a script, send the whole updated file again, every time.
- Don't send source links or source lists in replies.

# Content rules (Ink of Sinai)

- Tanakh only as authority. No Talmud, Midrash or commentators cited as sources; outside sources go in the pinned comment, never on screen.
- Say "God", never "Hashem". No Divine Name in on-screen Hebrew (show those verses in English).
- Verify every Hebrew claim in the Westminster Leningrad Codex before using it. Words like "only", "exactly", "every" and "first" must be checked, or dropped.
- Don't spend ElevenLabs credits without being asked; the user records the voiceovers.
- Make every visual for these videos with our own in-house engine. Never generate or source images with outside tools (Magnific, ElevenLabs, AI image models, stock or museum images).

# Writing scripts

- Research before writing: real demand (YouTube search titles and views, autocomplete), the channel's own hits, and the proven writing principles below. Never write from memory.
- A long-form needs one differentiating insight from the Hebrew that viewers haven't heard. Never just retell the story; the story comes in only as evidence for the insight.
- Picking a topic: run quick, time-limited reviewers that find topics on their own. Don't hand them candidates. Don't reuse stories from recent videos (04 covered Genesis 27–38).
- Structure:
  - The title and thumbnail promise is delivered in the first minute, with the strongest material first.
  - Link beats with "but" and "therefore", never "and then".
  - Stakes rise; re-hook around 3:00 and 6:00.
  - One or two open loops, all paid off.
  - A strong payoff, then end fast.
- Write as the viewer: after each beat, ask what the viewer wants next, and answer it in the next beat.
- Style:
  - Short spoken sentences, said once, concrete.
  - Anchor each Hebrew word in its sound or an image.
  - Start from what viewers already believe, and answer the skeptic.
- Banned AI phrasing:
  - "It's not X, it's Y"
  - "X isn't about A, it's about B"
  - "not just X, but Y"
  - "Here's the thing"
  - "This changes everything"
  - "So what does this really mean?"
  - "Let that sink in"
  - a rhetorical question answered right away
  - empty rhythmic triplets
  - closing lines that restate the point
  - vague "the whole story/book"
- Retention pass on every script: three quick reviewers read it line by line as three different viewers: a casual Bible fan who doesn't read Hebrew, a Hebrew-reading Jewish skeptic of typology, and a secular mystery fan who leaves within 10 seconds. Each marks where they'd leave and rewrites the line so it pulls into the next one. Merge the fixes, keeping Tanakh-only sources.
- Open on the concrete detail the thumbnail promises, never on what viewers already know. No "keep that in mind" filler. Every line must make the next one necessary; any line that sounds like an ending before the end gets a pull into what's next.
- One idea per beat. Don't stack extra proofs that bring in new names or terms; if a beat needs two sources, it's too complicated. The chain from one beat to the next must stay simple enough to follow on first listen.
- No chapter titles or section cards in scripts. Write plain narration only.
- Always write Hebrew words in Hebrew letters, never spelled out the way they're pronounced (no transliteration).
- Before sending: one quick, time-limited reviewer (facts + skeptical viewer), apply the fixes, then send only the script.

# Titles, thumbnails, captions

- Title: the searchable keyword plus the insight (e.g., "Goliath Was Dressed as the Serpent"). It must match the first minute and contain nothing a commenter can disprove.
- Thumbnail text never repeats the title; it adds a second hook. Proven on this channel: "Why Everyone in the Bible Meets Their Wife at a Well" with "IT'S ON PURPOSE." (264k views in 4 days, the channel's best).
- Thumbnail style that works here: gold ink on black, one figure or scene on the right, and a 2–3 word statement on the left ending with a period, with its key word in gold. Add a "look here" cue (a glowing circle) on the detail the video reveals. One subject, no clutter, no decorative extras, no Divine Name.
- Title patterns that perform in this niche: "Why Everyone in the Bible…", "The Hidden Reason…", "What Most People Miss About…", "N Patterns Hidden in…". Use the searchable keyword (the famous story), and nothing a commenter can disprove.
- Tags come from YouTube autocomplete research. In IG captions, put a blank line between lines. Strip `?si=` from YouTube links.
- Shorts:
  - Text follows the voiceover exactly, appearing as each line is spoken.
  - No fade-outs: scenes hold, then cut.
  - Text and graphics are centered together, inside the 9:16 safe zone, with no floating icons.
